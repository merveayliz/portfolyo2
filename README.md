## 📖 Proje Hakkında / About
**TR:** Portfolyo2, yazılım geliştiricilerin ve tasarımcıların projelerini, becerilerini ve özgeçmişlerini ziyaretçilere en şık ve anlaşılır şekilde sunmasını sağlayan modern bir kişisel web sitesi arayüzüdür.

**EN:** Portfolyo2 is a modern personal website interface that enables software developers and designers to present their projects, skills, and resumes to visitors in the most stylish and clear way possible.

---

## ✨ Özellikler / Key Features
- 🚀 **Proje Vitrini / Project Showcase:** Geliştirilen web projelerinin sergilendiği estetik kart yapısı. / Aesthetic card structure showcasing developed web projects.
- 🎨 **Modern UI/UX:** Ziyaretçileri yormayan, şık, minimalist ve profesyonel renk paleti. / Stylish, minimalist, and professional color palette that is easy on the eyes.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil telefonlar, tabletler ve masaüstü bilgisayarlarla kusursuz uyum. / Seamless compatibility with mobile phones, tablets, and desktop computers.
- 📬 **İletişim Alanı / Contact Section:** Ziyaretçilerin ve işverenlerin kolayca iletişim kurabileceği bağlantı ve form alanları. / Connection and form areas where visitors and employers can easily get in touch.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik web yapısı ve erişilebilirlik / Semantic web structure and accessibility
* **CSS3:** Özel stiller, esnek mizanpajlar (Flexbox/Grid) ve geçiş efektleri / Custom styles, flexible layouts, and transition effects
* **JavaScript:** Dinamik sayfa öğeleri ve kullanıcı etkileşimleri / Dynamic page elements and user interactions
